Kỹ năng chuyên môn

Các kiến thức và công nghệ đã được học và ứng dụng trong các bài tập lớn, dự án cá nhân:

  • Ngôn ngữ lập trình & Nền tảng: HTML5 (Semantic), CSS3 (Flexbox, Grid, Responsive), JavaScript (ES6+), Python.
  • Thư viện & Framework: ReactJS (cơ bản), Bootstrap 5, Tailwind CSS.
  • Cơ sở dữ liệu: MySQL, SQLite, MongoDB (cơ bản).
  • Công cụ & Quản lý mã nguồn: Git, GitHub, Visual Studio Code, Postman.
  • Kỹ năng mềm: Khả năng tự nghiên cứu tài liệu tiếng Anh, làm việc nhóm, tư duy giải quyết vấn đề.

Dự án tiêu biểu

1. Website Bán Sách Trực Tuyến (BookStore Web)

Mô tả: Dự án website thương mại điện tử đơn giản cho phép người dùng xem danh mục sách, tìm kiếm sản phẩm theo tên/thể loại, xem chi tiết và thêm sách vào giỏ hàng.

Công nghệ sử dụng: HTML5 Semantic, CSS3, JavaScript (DOM Manipulation, LocalStorage).

2. Phần Mềm Quản Lý Sinh Viên (Student Manager)

Mô tả: Ứng dụng desktop hỗ trợ giảng viên/nhà trường quản lý danh sách sinh viên, thực hiện các thao tác thêm, sửa, xóa, tìm kiếm và xuất thống kê điểm tổng kết.

Công nghệ sử dụng: Python, Thư viện giao diện Tkinter, Cơ sở dữ liệu SQLite.

3. Ứng Dụng Tra Cứu Thời Tiết (Weather App)

Mô tả: Trang web hiển thị tình hình thời tiết thời gian thực tại các địa điểm do người dùng nhập vào (nhiệt độ, độ ẩm, sức gió và trạng thái thời tiết) thông qua API công khai.

Công nghệ sử dụng: HTML5, CSS3, JavaScript ES6 (Fetch API, Async/Await), OpenWeatherMap API.
