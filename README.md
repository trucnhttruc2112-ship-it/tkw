Website Portfolio cá nhân được thiết kế hiện đại, mượt mà và tối ưu hóa trải nghiệm người dùng trên mọi thiết bị (Responsive Design). Đây là nơi tổng hợp thông tin cá nhân, các dự án thực tế, kỹ năng chuyên môn và phương thức liên hệ.

---

## 📌 Tính Năng Chính

- **Hero Section:** Trang chào mừng ấn tượng với hiệu ứng gõ chữ (typing effect) và nút kêu gọi hành động (CTA).
- **Giới thiệu (About Me):** Tóm tắt định hướng nghề nghiệp, mục tiêu và sở thích cá nhân.
- **Kỹ năng (Skills):** Hiển thị danh sách kỹ năng chuyên môn, công cụ và công nghệ sử dụng.
- **Dự án (Projects):** Danh sách các dự án nổi bật kèm hình ảnh demo, mô tả ngắn, công nghệ áp dụng và liên kết đến Source Code / Live Demo.
- **Kinh nghiệm & Học vấn (Experience / Education):** Timeline chi tiết quá trình làm việc và học tập.
- **Liên hệ (Contact):** Form gửi tin nhắn trực tiếp tích hợp EmailJS hoặc các liên kết mạng xã hội.
- **Giao diện (Dark / Light Mode):** Hỗ trợ chuyển đổi chế độ sáng/tối linh hoạt.
- **Tối ưu trải nghiệm (Responsive):** Hiển thị chuẩn xác trên cả Mobile, Tablet và Desktop.

---

## 🛠️ Công Nghệ Sử Dụng

- **Frontend:** HTML5, CSS3, JavaScript (ES6+) / React.js / Vue.js / Tailwind CSS
- **Icons & Fonts:** FontAwesome, Google Fonts
- **Deployment:** GitHub Pages / Vercel / Netlify
